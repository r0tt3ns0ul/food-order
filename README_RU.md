# FOOD CLUB PRO — Vercel + Supabase + Telegram

В этой версии есть:
- Публичное меню с категориями, корзиной и вводом номера ПК.
- Управление товарами в `/admin.html`: добавить, изменить, скрыть, удалить, цена, категория, описание, фото по URL.
- Заказы сохраняются в Supabase.
- Админ меняет статусы: Новый → Принят → Готовится → Готов → Выдан (или Отменён).
- Обновления статусов отправляются в Telegram-группу.
- Клиент может проверить статус по номеру заказа на главной странице.
- История последних 200 заказов в админ-панели.
- Вход в админку по паролю; сессия хранится в защищённой HttpOnly cookie.

## Важно
Эта версия требует Supabase для постоянного хранения меню и заказов. Нельзя сохранять заказы в файлы Vercel: serverless-файловая система не является постоянной базой данных.

## 1. Создай Supabase проект
1. Открой https://supabase.com и создай проект.
2. В Supabase открой SQL Editor → New query.
3. Скопируй весь файл `supabase/schema.sql` и нажми Run.
4. В Project Settings → API найди:
   - Project URL
   - `service_role` key (секретный ключ; не публикуй его)

## 2. Обнови GitHub
Загрузи/замени файлы и папки проекта в репозитории:
- `index.html`
- `admin.html`
- `api/`
- `lib/`
- `supabase/schema.sql`
- `vercel.json`
- `package.json`
- `README_RU.md`

## 3. Добавь Environment Variables в Vercel
Project → Settings → Environment Variables. Добавь для Production (и Preview, если используешь):

| Name | Value |
|---|---|
| `TELEGRAM_BOT_TOKEN` | новый токен Telegram-бота |
| `TELEGRAM_CHAT_ID` | ID группы заказов (обычно начинается с -100) |
| `SUPABASE_URL` | Project URL из Supabase |
| `SUPABASE_SERVICE_ROLE_KEY` | service_role key из Supabase |
| `ADMIN_PASSWORD` | придумай длинный уникальный пароль админки |
| `SESSION_SECRET` | случайная длинная строка минимум 32 символа |

Не вставляй эти секреты в HTML, GitHub, скриншоты или чат.

Пример генерации SESSION_SECRET на Windows PowerShell:
`[Convert]::ToBase64String((1..48 | ForEach-Object { Get-Random -Maximum 256 }))`

## 4. Redeploy
После добавления переменных сделай Redeploy последнего deployment.

## 5. Вход в админку
Открой `https://ТВОЙ-ДОМЕН.vercel.app/admin.html` и введи `ADMIN_PASSWORD`.

## 6. Как добавить фото
В админке в поле «Ссылка на фото» вставь прямую HTTPS-ссылку на изображение. Фотография должна быть доступна без авторизации. Можно оставить поле пустым — карточка покажет нейтральную заглушку.

## 7. Проверка
1. В админке добавь тестовый товар и сохрани.
2. Открой главную страницу и обнови её — товар появится в меню.
3. Оформи тестовый заказ.
4. В админке поменяй статус на «Принят», затем «Готовится».
5. Убедись, что обновления пришли в Telegram, а клиент может проверить статус по номеру заказа.

## Безопасность
- `SUPABASE_SERVICE_ROLE_KEY`, Telegram token, `ADMIN_PASSWORD`, `SESSION_SECRET` — только в Vercel Environment Variables.
- Не включай публичные права записи Supabase. Таблицы закрыты RLS, сервер использует service_role.
- Используй уникальный длинный пароль и не пересылай его в чат.
- Это стартовая админка; для публичного запуска с большим потоком посетителей стоит дополнительно включить rate limiting/WAF и резервное копирование Supabase.
