# Food Club — Vercel + Telegram

Готовый минимальный проект: статический сайт меню + серверный API для отправки заказов в Telegram.

## 1. Что нужно
- Аккаунт Vercel
- Telegram-бот, созданный через `@BotFather`
- ID Telegram-чата, куда бот будет отправлять заказы

## 2. Настройка Telegram
1. Создай бота через `@BotFather` командой `/newbot`.
2. Скопируй токен бота.
3. Добавь бота в групповой чат заказов.
4. Выдай боту право отправлять сообщения.
5. Узнай ID чата (для групп обычно отрицательное число, часто начинается с `-100`).

**Не вставляй токен в `index.html` и не отправляй его в переписку.**

## 3. Деплой на Vercel
1. Загрузи папку проекта в новый GitHub-репозиторий.
2. На Vercel нажми **Add New → Project** и импортируй репозиторий.
3. В настройках проекта открой **Settings → Environment Variables**.
4. Добавь:
   - `TELEGRAM_BOT_TOKEN` = токен от BotFather
   - `TELEGRAM_CHAT_ID` = ID чата заказов
5. Нажми Redeploy.

После деплоя сайт будет доступен по адресу Vercel.

## 4. Изменение меню
В `index.html` найди массив `const MENU = [...]` — там меняются названия, цены, категории, описания и эмодзи.

Важно: те же товары и цены нужно обновить в `api/order.js`. Сервер самостоятельно проверяет товары и пересчитывает сумму, поэтому нельзя доверять сумме, присланной браузером.

## 5. Проверка
Открой сайт, добавь товар, введи номер ПК и оформи тестовый заказ. Сообщение должно появиться в Telegram-чате.

## Примечания
- Номер ПК вводит сам клиент.
- Токен бота хранится только в Environment Variables Vercel.
- Это стартовая версия. Для публичного запуска желательно добавить ограничение частоты запросов и защиту от спама на уровне инфраструктуры.
